<h1>Vaulta — Animated Financial Landing Page</h1>

<p>
  A modern financial services landing page built using
  <strong>React, Tailwind CSS, GSAP, and ScrollTrigger</strong>.
  The project focuses on creating a polished, responsive interface with
  smooth scroll-based animations and interactive sections.
</p>


<img
  src="/public/assets/vaulta-preview.png"
  alt="Vaulta animated financial landing page preview"
  width="100%"
/>

<h2>Features</h2>

<ul>
  <li>Fully animated landing page</li>
  <li>Smooth GSAP animations</li>
  <li>Scroll-triggered animations using GSAP ScrollTrigger</li>
  <li>Animated sections</li>
  <li>Responsive design for desktop, tablet, and mobile</li>
</ul>

<h2>Tech Stack</h2>

<ul>
  <li>React</li>
  <li>Tailwind CSS</li>
  <li>GSAP</li>
  <li>GSAP ScrollTrigger</li>
  <li>JavaScript</li>
  <li>Vite</li>
</ul>

<h2>Animations</h2>

<p>GSAP and ScrollTrigger are used to create:</p>

<ul>
  <li>Hero entrance animations</li>
  <li>Fade and slide animations</li>
  <li>Scroll-based section reveals</li>
  <li>Staggered content animations</li>
  <li>Image and card animations</li>
  <li>Smooth section transitions</li>
</ul>

<h2>Project Purpose</h2>

<p>
  This project was built to practice advanced frontend animations in React,
  especially creating GSAP timelines across components and using
  <strong>ScrollTrigger</strong> to create animations based on the user's
  scroll position.
</p>
